## Counting method

Count distinct `owner/repository` pairs outside `Sanjays2402`, using the fully paginated public GitHub search `is:pr author:Sanjays2402 -user:Sanjays2402`, partitioned by creation date to avoid GitHub's 1,000-result search limit. Forks are counted as separate repositories; these are repository counts, not deduplicated organization or ecosystem counts. Submitted PRs include open, merged, and closed PRs and do not imply acceptance.

Direct merges use GitHub's PR merge metadata. For closed, unmerged PRs, review maintainer comments for explicit cherry-picking, adoption, preserved authorship, co-author credit, or incorporated tests and analysis. Work incorporated onto a maintainer branch counts even when the original PR was closed without merging. Generic thanks, duplicate fixes implemented independently, proposed future adoption, and automated statements that a bug is already fixed do not establish incorporation.

The accepted/incorporated total is a **verified lower bound**, not an exhaustive count of every acknowledgment, issue-only contribution, or commit authored outside a PR. Count each repository once, even if several contributions were incorporated by different routes. This is a static snapshot.
